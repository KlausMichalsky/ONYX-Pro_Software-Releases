# ONYX-Pro Software Releases

Official Raspberry Pi software releases for the ONYX-Pro robotic chess system.

ONYX-Pro is an integrated robotic chess platform combining custom mechanical design, dedicated electronics, embedded firmware and Raspberry Pi software.

This repository provides the official software images and binary packages specifically developed for the ONYX-Pro system.

## Downloads

Official software releases are published through [GitHub Releases](../../releases).

Each release may include:

- **Raspberry Pi System Image (`.img`)**: Complete operating system image with the ONYX-Pro software environment.
- **Software Package (`.zip`)**: Compressed distribution package containing the software image and related files.
- **Release Documentation**: Installation instructions, version information and SHA-256 checksums.

## Hardware Compatibility

The software is developed specifically for the ONYX-Pro Raspberry Pi hardware and its dedicated electronic and mechanical architecture.

It is designed to operate together with the official ONYX-Pro RP2040 firmware and the corresponding hardware configuration.

Compatibility with other hardware configurations is not guaranteed.

## Versioning

Official software releases use semantic versioning:

`vMAJOR.MINOR.PATCH`

Each release represents a specific version of the ONYX-Pro Raspberry Pi software.

Previous releases remain available through the GitHub Releases archive.

## Installation

Please follow the installation instructions included with each software package.

Always verify downloaded files using their corresponding SHA-256 checksums before installation.

Use the software and firmware versions specified as compatible for your ONYX-Pro hardware configuration.

## Project

ONYX-Pro is a custom robotic chess system featuring a SCARA robotic arm, magnetic piece detection, RP2040 closed-loop motion control and Raspberry Pi software integrated with the Stockfish chess engine.
